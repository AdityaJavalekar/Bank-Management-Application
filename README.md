# Bank-Management-Application

Bank Management System (C++)A console-based Banking Application built in C++ that simulates essential real-world banking operations. The system uses Object-Oriented Programming (OOP) concepts and file stream handling (fstream) to maintain persistent customer records across program sessions.Key FeaturesAccount Creation: Register new bank accounts with unique account numbers, holder names, and initial balances.Deposit Operations: Safely credit funds to existing accounts with strict input validation.Withdrawal Operations: Debit funds with real-time balance checking to prevent overdrafts.Balance Inquiry & Account Info: View account details and current balances instantly.Display All Accounts: View all registered accounts in a formatted data table.Persistent Data Storage: Saves data permanently in bank_records.txt using pipe-delimited values (accNum|name|balance).Safe Record Updates: Uses dynamic temporary file swapping (temp.txt $\rightarrow$ bank_records.txt) for updates without file corruption risks.Core OOP Concepts AppliedEncapsulation: Account attributes (accountNumber, accountHolder, balance) are kept private within the BankAccount class and modified safely through public member functions (deposit, withdraw).Data Integrity & Validation: Built-in safeguards check for invalid amounts, duplicate account numbers, and overdraft attempts.Abstraction: Internal file formatting and parsing logic are abstracted away behind simple class interface methods like toFileString() and displayDetails().Prerequisites & RequirementsC++ Compiler: GCC / G++ (C++11 or higher recommended).Compatible IDEs: Visual Studio Code, Code::Blocks, CLion, or OnlineGDB.Important Note for OnlineGDB: Ensure that the language setting at the top right is set to C++ (e.g., C++17 or C++20). If set to C, standard C++ libraries such as <iostream> will result in compilation errors.How to Run the ProgramOption 1: Running in OnlineGDBOpen OnlineGDB.Select C++17 or C++20 from the top-right Language dropdown.Copy the main.cpp code into the editor.Click the green Run button at the top.
